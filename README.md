# ECO Bengaluru demo

Open `index.html` in a browser (or double-click `run_demo.bat`). No database server or SQL setup is required. Demo accounts, household registrations, collections, verification decisions, points, redemptions, and waste reports are saved in browser storage on this device.

## Demo accounts

- Admin: `9000000001` / `EcoAdmin@123`
- Garbage Collector: `9000000002` / `EcoCollect@123`
- Verification Centre: `9000000003` / `EcoVerify@123`
- Demo customer: `9000000004` / `EcoHome@123` (household card `SS-1024`)

Customers can create additional household accounts from the login dialog. Each receives a unique card ID. The collector records a bag against that ID, the verifier approves or rejects it, and approved bags earn 10 GP per kg. Points and redemptions are linked to the household card.

This is a browser-only hackathon demo. Data is available in the browser profile and device where it was entered.
